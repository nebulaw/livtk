# Icons

[Boxicons](https://boxicons.com) v3.0.8, the free *filled* style, 24 × 24, unmodified. Each file
keeps its original name and the credit comment Boxicons puts in it.

The icons are licensed under CC BY 4.0, separately from livtk's MIT code: see
[LICENSE.txt](LICENSE.txt), as Boxicons ships it. Attribution is the credit comment in each file
and the note in the project README.

More than the app uses lives here, kept for later work. Only the icons the app names are
compiled into it; the rest cost nothing.

To add one, download it from boxicons.com in the same style (filled, regular weight) and drop the
SVG here under its own `bx-` name.
